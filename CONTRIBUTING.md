# Contributing

Contributions that improve reproducibility, public API probes, analysis correctness or future-iOS compatibility are welcome.

Do not submit captured commercial music, video/game audio, device identifiers, provisioning profiles, signing identities, credentials, private APIs, jailbreak code or modified third-party applications. Use synthetic signals and redact local paths/team identifiers from logs.

For a new iOS/Xcode result, use the issue template and include the exact SDK target, compiler output and runtime evidence. A claim of per-App isolation/control must include simultaneous distinguishable sources and FFT evidence.
