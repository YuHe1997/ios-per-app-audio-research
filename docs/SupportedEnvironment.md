# Supported Environment

The initial release was verified with Xcode 27.0 (27A266a), iPhoneOS 27.0 SDK, an iPhone 15 Pro Max on iOS 27.0, built-in speaker, and 48 kHz stereo capture.

The unsigned generic-device build requires no Apple account. Installing on a physical device requires the contributor's own Apple signing team and normal device setup.

Older/newer SDKs may expose different availability annotations. Submit changed results with exact compiler/runtime evidence.
