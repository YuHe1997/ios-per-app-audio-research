# Future iOS Version Watch

For each major Xcode/iOS beta, rerun and record:

- ScreenCaptureKit application filters
- `SCRunningApplication`
- `SCShareableContent`
- `includedApplications`
- single/multiple application picker modes
- `AudioHardwareProcess` or equivalent process objects
- `CATapDescription`
- `AudioHardwareCreateProcessTap`
- process PID/bundle/running-output properties
- any direct per-process gain API

An iOS 27 failure that compiles on a future native iPhoneOS target is only a candidate. Continue through link and physical-device runtime, then use simultaneous distinguishable sources and FFT for Level 2/3 claims.
